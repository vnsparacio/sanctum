## External blockers before production activation

The current environment exposes neither `LINEAR_API_KEY` nor a callable
`linear_graphql` tool. Therefore the actual workspace metadata, existing
duplicates, templates, source-label group, and mutation responses have not been
observed live. All role `write_enabled` values and schedules remain false.

The same blocker prevents the required real end-to-end implementation smoke:
creating/choosing a controlled Linear issue, owner-authorizing it, dispatching
through Symphony, attaching the resulting GitHub PR, moving to Human Review,
and reviewing that real PR. The implementation supervisor has passed a local
fake-service kill/incident smoke, but that is not represented as the live
lifecycle proof.

Exact owner action: establish Linear authentication locally on the Mac without
sharing the token, then resume this project for metadata qualification and the
controlled smoke. No source redesign should be necessary unless live metadata
differs from the synthetic contract.

## Deliberately deferred

Splunk, Galileo, HEC, telemetry pipelines, Splunk MCP, and an Observability
Steward are out of scope. The extension seam is the stable JSONL run log,
incident receipt, and role/run identity. No current feature depends on Splunk.

Automatic merge and automatic Done transitions are also deferred by policy,
not by implementation incompleteness. The human owner remains the final merge
authority.

## Repository and runtime boundaries

The legacy historical repository and the external Symphony source were not
modified. The private VinceAI runtime was not amended. Generated
agent logs, state, locks, shadow artifacts, and incidents remain outside Git.

The feature branch must be reviewed by PR into `v1.2-dev`; do not merge it
automatically and do not begin a sibling V1.2 project from this branch.
