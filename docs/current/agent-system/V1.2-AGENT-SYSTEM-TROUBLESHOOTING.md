# V1.2 agent-system troubleshooting

## Configured model unavailable

Run `models-check`. The current ChatGPT account and installed Codex must expose
the exact configured ID and reasoning value. There is no fallback. Update the
central mapping only through review after confirming the live catalog.

## Role already running

An exclusive lock exists. Check the PID and matching JSONL run log. A living
owner or a lock younger than the stale threshold is not removable. Dead locks
older than the threshold are recovered automatically; malformed locks fail
closed and require owner inspection.

## Codex stopped with a budget reason

`wall_clock_budget`, `tokens_budget`, `turns_budget`, `stall_budget`, and
`output_budget` are expected safety outcomes. Do not raise a ceiling merely to
make a run pass. Reduce scope/source count first, then change a budget through a
reviewed configuration commit with shadow evidence.

## Malformed model output

The host rejected a response that passed through the model boundary but did not
meet semantic validation. Keep writes off. Check unknown evidence IDs, missing
`product-discovery`, community-only sources, unqualified files/criteria, and
verdict/finding contradictions. Fix prompts or schemas and repeat shadow mode.

## Linear authentication unavailable

The token is intentionally absent from source and child prompts. Set
`LINEAR_API_KEY` only in the owner-controlled Mac process or connect supported
Linear tooling. Never put the token in chat. If metadata cannot be inspected,
keep all `write_enabled` flags false and all schedules disabled.

## Linear metadata mismatch

Do not recreate, rename, delete, or silently remap existing workspace objects.
Reinspect the project/team/state/label/template IDs. If names genuinely differ,
stop for an authority decision and make a reviewed source change. Never include
`symphony` in a management proposal.

## Symphony binary unavailable

Set `SANCTUM_SYMPHONY_BIN` to an executable reviewed binary outside Sanctum. A
development binary adjacent to `mise.toml` is launched through `mise`; ensure
the pinned Erlang/Elixir toolchain is installed. The wrapper passes the required
engineering-preview acknowledgement itself.

## Symphony state API unavailable

The supervisor allows 30 seconds for startup/transient failure. It then kills
the process group and writes a `state_api_stall` incident. Confirm the configured
loopback port is free, inspect the private Symphony log, and validate WORKFLOW
with the installed reference schema. Never expose the dashboard publicly.

## Symphony budget incident

Read the private incident receipt and JSONL log. Turn and token totals aggregate
across observed continuation sessions; elapsed time persists in the private
ledger. The service deliberately leaves Linear untouched. A later Human Review
or completed absence ages the ledger entry out before a separately authorized
Rework run.

## Reviewer rejects a packet

Capture an unmerged PR targeting `v1.2-dev`, the deterministic issue branch,
Human Review state, acceptance criteria, workpad, bounded diff, CI, validation,
and only relevant source context. Unknown files and criteria are not accepted.
Reviewer and implementation contexts must remain separate.

## Audit reports owner_home or secret material

Remove owner-specific paths or secrets from source and use an environment
variable or external private metadata file. Do not refresh the source manifest
until the source itself is safe and reviewed.
