## Build and deployment expectations

Run `make deps`, `make build`, `make test`, and `make audit`. Inspect an existing `.venv` before dependency bootstrap; do not recreate it blindly. Tests expect ordinary file-creation mask 022; private runtime/evidence uses owner-only access. An initial harness mask of 077 broke a permission-rejection fixture; the normal test environment passed without changing the assertion.

Use `make setup PREFIX=/absolute/private/prefix` only on an absent/empty prefix or matching verified installation. Run `make doctor PREFIX=/absolute/private/prefix` after setup and supported amendments. Doctor verifies source, core pins and rendered configuration; optional live health must be checked separately. Its generic optional-integration label is not an enrollment inventory. See [configuration](configuration.md) for web/MCP bootstrap and private amendments. Stop the candidate gateway before amendments.

## Rollback

Follow [migration and rollback](migration.md). End candidate gate sessions, perform managed GPU stop and verify provider-side zero ownership, leases and active requests before stopping cleanup. Preserve persistent model storage and private receipts. Never delete uncertain allocation state.

Stop the gateway with `make down PREFIX=/absolute/private/prefix`. Stop only candidate component processes after checking their recorded identity; use Ctrl-C for owner Terminal brokers. Retain private runtime data. Restore only a matching configuration transaction with `scripts/configure.py --prefix /absolute/private/prefix --rollback /absolute/private/transaction`, with the gateway stopped. Do not replace entire databases.

Legacy source/configuration/services were not replaced. If restoring a legacy model launcher, first stop the verified candidate model to prevent competing loaded servers. Preserve the V1 tag and all Project 0B commits; rollback needs no force reset or push. The external handoff contains exact local process/receipt locations and final source commit.
