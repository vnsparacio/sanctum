# Lessons retained

Inspect what is loaded, not just what was edited. Compiled plugins, generated metadata and live links can diverge from source. Virtual environments are path-sensitive. A version command or provider availability listing does not prove readiness.

Test the model, agent, plugin, broker, wrapper, provider and UI as separate contracts. A correct schema does not imply the right source. Email receipt time is not an event date, and a filename is not document content.

Small models benefit from small explicit tools, bounded outputs and deterministic utilities. Shortening descriptions can remove essential semantics. Generic prompting, bigger models and additional cache/concurrency did not reliably fix architectural problems.

Persist intent before mutation. Ambiguous allocation is not an explicit rejection. Reconcile before retrying, confirm deletion and avoid claiming a remote hard stop without evidence. Keep cleanup separate from allocation authority.

Sanitize before creating public history. Keep development evidence private by default. Containerization should reduce setup without granting Docker broad host access. Preserve failed tests and realistic operational limits.
