## Reviewed repair

- For a non-private public weather request with exactly one explicitly supplied five-digit ZIP, Mac query minimization retains that ZIP. Numeric identifiers in other contexts and ZIPs in private context are not automatically sent to public search. Explicit local-source recency (such as “my latest email”) does not trigger public web retrieval.
- The Source-First coordinator rejects ZIP-weather search candidates whose URL or title does not identify that ZIP. It marks the pack adequate only after fetching weather facts, rather than treating any nonempty unrelated page as sufficient.
- The local OpenClaw handoff partitions explicit Gmail, Messages and Calendar requests by source family. A prompt-build tool cap and pre-tool guard prevent wrong-family calls. A personal-source final answer is suppressed when no requested-family tool call succeeds. Source-First evidence answers have no optional tools. This is a fail-closed boundary, not a new permission or provider fallback.
- A session contract test checks that one eligible Gemini audit grant spans `ask` and `ask-strong`, while the frontier answer still requires its own exact approval. This documents the distinction between the audit session and answer disclosure; no hosted answer approval was removed.
