# Project 3G-I-B offline implementation handoff

Project 3G-I-B implements the versioned `sanctum-work-intent/v1` boundary. PRIVATE_LEAD now emits only a closed semantic intent (`TOOL_PROPOSAL` with capability and semantic arguments, `FINAL`, or `ESCALATION`). The Mac derives every canonical ToolProposal binding from a captured inference context: proposal ID, request ID, turn, reasoner, capability digest and task binding. Canonical Project 1 validation, authority, invocation, result envelope and egress remain unchanged.

`gate/foundation/work-intent.mjs` derives each semantic schema from the published canonical schema after removing `task_id`. It rejects host-field injection, missing/extra/wrong-type/enum semantic values, and unavailable capabilities; it does not coerce or repair model input. `work-mode.mjs` sends the current closed JSON schema as `state.workIntent`, adds a top-level one-turn correction envelope, removes it after a valid intent, applies the correction limit to visibility and semantic failures, and records content-minimized structural diagnostics only.

`PrivateLeadBackend.propose` now requires the versioned intent transport and sends the actual schema through the pinned vLLM OpenAI-compatible `response_format.json_schema` field. There is no unconstrained fallback. The reviewer uses a separate terminal-only intent schema and receives no work capability branches.

Before each inference, Work Mode captures a host workspace fingerprint from bounded `diff` and `status` digest/size facts. A mutation rechecks it before authority/execution; a changed fingerprint stops with `WORKSPACE_STATE_CHANGED`. The coordinator separately advances a host workspace generation after successful mutation or uncertain completion. Existing worker path traversal, symlink, hard-link, Git-internals and Git check/apply controls remain in place. The existing serialized task path and authenticated worker call preserve one-writer ownership; no model response is rebound to a newer turn or snapshot.

Offline coverage includes semantic positive/negative validation, host-field injection, capability visibility/phase narrowing, canonical translation, one-correction behavior, stale workspace fingerprint refusal, backend response-format transmission, reviewer terminal schema separation, malformed/transport classification, authority/egress/evaluator/reviewer checks and existing containment tests. No graded task fixture was added as a prompt example.

Validation required and completed after source edits: focused Work Mode tests, full packaged tests, canonical build and source audit. No private runtime was amended, no GPU was allocated, and no source freeze, doctor, push or PR was performed. The source tree remains the only changed artifact.

Rollback is one local commit revert before deployment. Do not partially revert the semantic adapter and coordinator independently. If this implementation is installed later, use the supported stopped-gateway amendment procedure, perform a reviewed source freeze, run doctor against the private prefix, then run only the separately authorized bounded live plan in the root-cause design. Project 3G remains unaccepted.
